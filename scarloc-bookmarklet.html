ScarLoc

Shows the location of the other side of a WebRTC connection, using free public lookup services that need no API key or account.

ScarLoc Drag this button onto your bookmarks bar.

How to use it

  1. Drag the button above to your bookmarks bar.
  2. Open the site that uses WebRTC (video chat, calls).
  3. Click the ScarLoc bookmark before the call connects.
  4. The window fills in when a connection is detected.

If dragging doesn't work, create a bookmark by hand and paste the copied code into its URL field. The script tries ipwho.is, then freeipapi.com, then ipapi.co, so a rate limit on one falls through to the next. Free services can still throttle heavy use. Sites with strict security policies may block bookmarklets or the lookup request.
